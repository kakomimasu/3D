# 囲みマス 3D

[囲みマスのVRビューア](https://github.com/kakomimasu/viewer/tree/main/public/vr)を参考にした、ブラウザで対戦を眺める3Dビューアです。Three.jsで盤面を描画します。

## 起動

```sh
npm install
npm run dev
```

表示されたローカルURLを開いてください。`npm run build`で`dist/`に静的ファイルを出力します。`npm test`でデータ処理を検証できます。

## 操作

3Dスタジオを画面の横幅いっぱいに表示します。対戦者・得点・ターンは会場内の大型LEDボードで確認できます。

- カメラはゆっくり左右に往復します。ドラッグ・拡大縮小中は停止し、操作終了の4秒後に再開します。「操作」の「カメラを自動で動かす」で切り替えられます（端末の動きを減らす設定が有効な場合は初期状態でオフ）。
- ドラッグ：回転、スクロール／ピンチ：拡大縮小、右ドラッグ：移動
- 「スタジオ」「選手席」「盤面」「真上」「↺」：カメラ切り替え／リセット
- マスにカーソルを合わせる：座標、得点、壁／領域の詳細
- 「操作」メニュー：マスの得点表示、デモへの切り替え、再生・一時停止・1ターン送り
- ヘッダーの「ゲーム一覧」で最近の公開対戦を表示。対戦者・日時・状態を確認して選択、更新・再試行が可能
- ゲーム一覧内で対戦IDを入力して接続（`?id=対戦ID`にも対応）

実対戦はVR版と同じ公開SSEエンドポイント `https://api.kakomimasu.com/v1/matches/stream` を使用します。接続は観戦のみで、対戦操作や認証情報を必要としません。サーバーの公開設定・稼働状況・CORSにより利用できない場合は画面に接続状況を表示します。

壁は高めの濃色タイル、囲み領域は淡色、駒は青／赤の立体マーカーで表示します。得点はサーバーの集計を優先します。

デモは表示確認用の生成データで、公式ルールによる対戦シミュレーションではありません。VRヘッドセット向けの操作は未実装です。

## 競技スタジオ

高専プロコンの競技会場をイメージしたオリジナルの番組セットです。中央の対戦台、得点と対戦者が連動する大型LEDボード、照明トラス、左右の選手席・観客席を3Dで配置しています。「スタジオ」「盤面」「真上」で視点を切り替えられます。

会場構成の参考: [高専プロコン大会パンフレット](https://www.procon.gr.jp/wp-content/uploads/2016/12/27_Pamphlet.pdf)。公式会場の再現や公式配信ではありません。

## ロゴ

ヘッダー・ファビコン・スタジオの大型LEDボードには、[囲みマス公式ロゴ](https://kakomimasu.com/img/kakomimasu-logo.svg)を使用しています。`public/img/kakomimasu-logo.svg`に元のSVGを変更せず保存し、縦横比を維持して表示しています。ロゴの権利は元の権利者に帰属します。

ページを開くと、開始日時が最新の公開ゲームを自動表示します。`?id=対戦ID`がある場合は指定ゲームを優先します。自動選択時はURLにIDを固定しないため、再読み込みでもその時点の最新ゲームを取得します。取得失敗・タイムアウト・ゲームなしの場合は理由を表示してデモに戻ります。観戦中に新しいゲームが追加されても自動では切り替えません。

選手席には青・赤各2人の学生風キャラクターを配置しています。パーカーなどの私服、参加証、着席した姿勢とキーボードに伸ばした腕を立体で表現しています。「選手席」カメラで近くから確認できます。

## TypeScript開発

アプリ本体・3Dモデル・テスト・Vite設定はTypeScriptです。`src/types.ts`に対戦データや視点の型を定義しています。APIの入力は`unknown`として受け取り、実行時の検証後に利用します。

- `npm run typecheck`: strictモードでアプリ・テスト・Vite設定を型チェック
- `npm test`: tsxとNode.jsのテストランナーでTypeScriptのテストを実行
- `npm run build`: 型チェックの成功後にViteでビルド（GitHub Actionsでも同じ手順）

## 実況字幕

画面下部に実況字幕を表示します。受信した得点・ターン・逆転・終了結果から文を生成し、対戦の更新に合わせて切り替えます。同じ状態の再受信では繰り返し更新しません。音声の読み上げはありません。
