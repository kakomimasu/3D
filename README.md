# 囲みマス 3D

[囲みマスのVRビューア](https://github.com/kakomimasu/viewer/tree/main/public/vr)を参考にした、ブラウザで対戦を眺める3Dビューアです。Three.jsで盤面を描画します。

## 起動

```sh
npm install
npm run dev
```

表示されたローカルURLを開いてください。`npm run build`で`dist/`に静的ファイルを出力します。`npm test`でデータ処理を検証できます。

## 操作

- ドラッグ：回転、スクロール／ピンチ：拡大縮小、右ドラッグ：移動
- 「立体」「真上」「↺」：カメラ切り替え／リセット
- マスにカーソルを合わせる：座標、得点、壁／領域の詳細
- 「得点を表示」：数字の表示切り替え
- デモの再生、一時停止、1ターン送り
- 「ゲーム一覧から選ぶ」で最近の公開対戦を表示。対戦者・日時・状態を確認して選択、更新・再試行が可能
- 対戦IDを入力して接続（`?id=対戦ID`にも対応）

実対戦はVR版と同じ公開SSEエンドポイント `https://api.kakomimasu.com/v1/matches/stream` を使用します。接続は観戦のみで、対戦操作や認証情報を必要としません。サーバーの公開設定・稼働状況・CORSにより利用できない場合は画面に接続状況を表示します。

壁は高めの濃色タイル、囲み領域は淡色、駒は青／赤の立体マーカーで表示します。得点はサーバーの集計を優先します。

デモは表示確認用の生成データで、公式ルールによる対戦シミュレーションではありません。VRヘッドセット向けの操作は未実装です。

## GitHub Pages

公開URL: https://kakomimasu.github.io/3D/

`main`へのpushでGitHub Actionsがテスト・ビルドを実行し、`dist/`をGitHub Pagesへ公開します。PagesのSourceは **GitHub Actions** を選択します。

Viteのベースパスは`/3D/`です。ローカル開発時も`http://127.0.0.1:5173/3D/`で開いてください。

## 競技スタジオ

高専プロコンの競技会場をイメージしたオリジナルの番組セットです。中央の対戦台、得点と対戦者が連動する大型LEDボード、照明トラス、左右の選手席・観客席を3Dで配置しています。「スタジオ」「盤面」「真上」で視点を切り替えられます。

会場構成の参考: [高専プロコン大会パンフレット](https://www.procon.gr.jp/wp-content/uploads/2016/12/27_Pamphlet.pdf)。公式会場の再現や公式配信ではありません。
